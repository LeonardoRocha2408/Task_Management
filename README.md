# Task Management
This project is a task management tool similar to Trello. It goal is to allow people or companies to manage their activities more easily.

## Features
- Create, delete and change password account
- Login account 
- JWT authentication
- HttpOnly
- Password hashing

## Technologies
- C#
- ASP.NET Core 
- Entity Framework Core
- Git
- MySQL

## Getting started
- Clone the repository
- Configure your "appsettings.json"
- Configure the Swagger
- Update the database connection string
- Run the Entity Framework migrations
- Run the project
